# ahktrix Agent Guidelines

- **Project**: ahktrix (AutoHotkey v2 QoL utilities & CapsLock modifier layer).
- **No Comments**: Strictly zero comments allowed in `.ahk` code files.
- **Relative Paths**: Always use relative paths from `A_ScriptDir`.
- **Validation**: Always run `AutoHotkey64.exe /validate main.ahk` before completing changes.
- **Git Protocol**: Atomic lowercase commits in English. Features in `feature/...` merged to `main`.
- **Skill Reference**: Detailed passport and architecture available in `.agents/skills/ahktrix/SKILL.md`.
